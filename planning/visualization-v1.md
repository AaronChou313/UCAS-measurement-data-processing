# 可视化教材 V1.0 建设与验收记录

日期：2026-10-15。内容基线为PR #1合并后的 `f0659dd`；完整建设在 `visualization-full-build` 分支进行。本文记录实施事实和取舍，不把自动测试、独立代码复核或作者模拟阅读称为真实学生学习效果实验。

## 1. 教学与实现结果

保留六章、原学习顺序、300条知识清单、原标题及锚点。新增图在定义/推导/数例之后承担一个主要观察任务，图前提醒固定条件，图后解释规律和边界；不复制正文为一套大型计算工具。

本轮新增 **44处静态辅助、71幅确定性SVG和一个四阶段Kalman演示**。本轮对既有试点之外的29项候选逐项作了处置；这些图分布在各自需要的位置，并非要读者同时掌握44个工具。V01/V14/V18沿用已精简试点；V14只改相关性，V18只推进离散时间，V26只按固定模型切换阶段。其余优先静态，无新增前端依赖、自动播放或3D。

### 各章的主要增益

- 第一章沿用V01对象/坐标、主动/被动、运算顺序六图，不重复建设。
- 第二章：密度面积与累计高度；原观测和均值抽样分布；固定真值与移动区间；箱须、核叠加、QQ配对；参数/观测两个空间；先验与后验。Newton用固定三帧说明切线替代。
- 第三章：均值带和新观测带；不同损失的残差方向；相同摘要的不同结构；方波跳点、幅相和有符号sinc；混叠、补零/延长记录与窗的权衡分开讲。
- 第四章：线性协方差传播与非线性余项分开；实现/过程、非平稳随机游走、精确GGM谱和相关；秩亏参数不唯一但拟合唯一；三种椭圆采样机制对照。保留V14已知总体参数概率解释。
- 第五章：沿用Markov三个聚焦辅助；高维四量分别列分母和分布；每折重拟合的信息边界；L1尖角、Ridge奇异方向、软阈值分开。
- 第六章：SVD用标记向量显出旋转，再独立显示截断；PCA得分/投影脚/残差；传播相位热图与白化不独立反例；似然尺度两项；Kalman预测/观测/修正；分支反向、重叠卷积梯度；数组轴与唯一键填表。

## 3. 数学与来源核查

### 高风险关系的实际验证

- V02：X=(1,2)ᵀ、y=(2,1)ᵀ，β̂=0.8；拟合(0.8,1.6)、残差(1.2,−0.6)，Xᵀe=0，5=3.2+1.8。秩亏例参数和为2，唯一拟合(2,0)，最小范数(1,1)。
- V26：F传播得先验(10,1)、P⁻=[[4,1],[1,2]]；ν=2、S=5、K=(0.8,0.2)ᵀ；后验(11.6,1.4)，Joseph P⁺=[[0.8,0.2],[0.2,1.8]]，独立信息矩阵逆/信息均值一致。位置m、速度m/s，K第二分量s⁻¹。本特定Q=0例预测位置方差不增，图上明确提醒，不暗示常见预测一定保持不变。
- 区间：独立数值积分核正态95%分位及t₄临界点；预测方差比均值方差多s²项。模拟种子固定但不强制命中率95%。
- Fourier：box积分交叉核sinc；直接DFT核Parseval；40/60 Hz别名等式、补零同一频点复值一致；窗幅值与PSD归一不混。Hann长度2零窗权和拒绝返回NaN。
- GGM：课程h递推8192项Fourier和与独立解析传递谱一致；κ=−2退化到φʲ，φ<1和无限过去平稳初始化声明在图旁。RW另画绝对时刻方差，不硬套平稳PSD。
- Ridge/Lasso：接触点按KKT核验，目标尺度分开；小奇异方向在λ≈0加密并核实(0.01,0.5)，不让折线失真。
- SVD/PCA：独立Gram矩阵特征值、正交性、Frobenius误差、投影残差正交与能量分解核验。六点Gram=[[12,6],[6,4]]，最优28.154966°、保留平方和15.21110255/16。
- NN/CNN：全部分支参数梯度与中心差分核验；卷积额外用非均匀上游梯度[[1,2],[3,4]]核反传，避免仅测对称数据掩盖覆盖错误。中心零是贡献抵消。

两名独立只读审查代理分别核数学和来源/语境；他们未编写实现。其审查找到的近0采样、Hann边界、图框、箭头遮盖、指数标注、相位单位等问题已修复。开发者的单元测试、独立解析实现和代理复核相互补充，均不等于学生实验。

## 4. 工程、内容与可复现性

- `full-math.mjs`只保留小型明确模型，`ScienceFigure.vue`是图目录/静态SVG的薄渲染层，`KalmanSteps.vue`独立固定模型。未引入新的前端库、Python浏览器运行时或大型通用框架。
- 每个SVG有唯一前缀title/desc、真实坐标和本地模型说明；无JS的生产HTML包含全部静态图。Kalman初始图与静态数值对照仍可读，控件仅在挂载后显示。
- 小屏单列、等比例几何、主题变量、文字/线型区分；不对科学PNG统一反色。
- `source_models.py`是作业实际使用的共轭/核函数，也随网站下载主脚本一起提供；避免下载主脚本后缺少本地模块。
- 新增`check:course-integrity`：逐字保留基线六章标题/显式锚点、1496个原内容区块、2635处原公式及300条清单；仅两处明确列名的SOI上下文允许修订。另实际审阅Git差异中的新增/移动/源修正，不能把这一脚本当作全部内容零遗漏证明。
- CI顺序为数学（含无科学依赖的Python helper）→内容保留→SVG一致→**单次构建/链接/MathJax**→实际SSR。任一失败不上传/部署；PR不部署，main合并后才发布。
- `release.json`标记版本和构建commit（Actions使用GITHUB_SHA），用于核对线上是否确实更新，不根据首页文字自行猜测。

运行命令：

```sh
npm run test:visualizations
npm run check:course-integrity
npm run figures:check
npm run docs:build
npm run check:visualization-pages
git diff --check
```
