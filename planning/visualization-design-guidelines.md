# 课程可视化组件设计与验收规范

适用范围：本课程 VitePress 教材。依据 V01、V18、V14 试点及后续认知负荷重构形成；当前规范以本轮精简方案为准，早期完整计算面板的设计记录保留在试点报告中，不作为新组件默认模板。

目标是让读者更快读懂数学对象、通过观察建立联系。数学正确、功能完整和构建成功是必要条件，不能单独证明学习效果。

## 1. 先确定一个主要理解障碍

开发前读完所在小节及前后衔接，写出读者正在问的一个问题。再列出解决它所需的最少对象、固定条件、变化量与预期观察。

| 当前问题 | 本轮选择 | 明确交给正文的内容 |
|---|---|---|
| 同一向量换坐标，与旋转对象有什么不同？ | V01 并列静态 SVG | 矩阵推导、一般变换性质 |
| 为什么目标概率汇总所有来源？ | V18 5.1.3 两路径静态图 | 完整矩阵及两个目标状态的递推、概率守恒证明 |
| 反复迁移后分布怎样变化？ | V18 5.1.4 两条概率条，仅改变 k | 平稳方程、闭式解与收敛证明 |
| 有唯一平稳分布为什么仍不收敛？ | V18 5.1.5 固定周期链四时刻图 | 周期、不可约、正则性及单位矩阵反例 |
| 相关性变了，为什么椭圆倾斜而边缘标准差不变？ | V14 一个 ρ 滑块、95% 轮廓、固定投影框 | 特征分解、方向方差、半轴计算及投影证明 |

只有学习目标确实不同，才拆到不同位置；不要把同一运算拆成许多需要额外导航的界面。V18 分成三项，是因为“汇总来源”“时间演化”“收敛反例”分别依赖 5.1.3、5.1.4、5.1.5 的知识，不能在尚未定义平稳时让读者同时掌握全部概念。

## 2. 六项认知负荷原则

### 最小必要信息

每个默认可见元素都要回答：“少了它，当前观察任务是否会失败？”

V14 不再默认列 C、两个特征值、方向角、四组尺度与投影表；它们虽正确，却与观察形状竞争注意力。保留固定 σ、概率尺度和已知参数条件，因为缺少这些信息会直接误导读图。

### 渐进式呈现

先呈现简单而完整的关系，再在知识实际出现的位置深入。必要条件应靠近图形；复杂推导回到正文。不要通过折叠整套旧面板假装完成精简。本轮没有新增进阶折叠区，原计算已经由正文完整覆盖。

### 交互增量价值

比较静态图是否已经足够。V18 两来源相乘再相加，用一图就能呈现，不需要三阶段按钮。改变时间才能观察概率条接近平稳线，因此时间控制有明确价值。周期链的四个离散时刻足以显示交替，默认不再提供模型切换。

### 图文职责分离

正文负责动机、定义、符号、推导、适用条件与严格结论；图形负责空间、流向、形状和变化。在新语境提醒关键参数，不复制整段讲义。V18 演化图仍说明每步的 5%/3% 迁移概率、初分布与平稳标记，让跳读者能理解模型。

### 认知负荷审查

第一次看见图时，读者应能迅速指出主要对象、变化量和下一动作。验收时先不读长说明，尝试预测并操作；若必须先理解面板结构、多个表或隐藏状态机，应重审设计。不能以“增加一段操作说明”替代界面调整。

### 删除优先

按以下顺序处理复杂界面：删重复 → 交还正文 → 减少同时出现的对象/参数 → 必要时按学习目标拆分。最后才考虑局部展开。不要优先增加说明、颜色、按钮和折叠层级。

精简不得删除必要数学条件；减少按钮或缩短组件本身也不是学习效果证据。

## 3. 图前、图中与图后

- 图前用一至两句提出观察问题，说明固定条件；不要列一页操作手册。
- 图中优先给对象、方向、尺度及必要数值。相同对象保持相同符号，输入与结果有明确位置。
- 图后解释观察到的一个规律，并点明最可能误读的边界；一般推导与其他任务留在正文。
- 跨越较长篇幅的关键模型适时提醒，但不机械重复完整符号表。
- 维持原章节、来源、知识点和锚点。移动组件须检查旧锚点仍有效；V18 的 `#v18-markov` 保留，新增来源 `#v18-sources` 和周期 `#v18-periodic`。

## 4. 数学含义与排版

- 遵循《阅读指南与统一符号》；区分随机状态、状态分布和实现值。概率条不是居民运动轨迹。
- 当前状态概率、条件转移概率、联合路径贡献、下一状态概率不能共用含糊标签。V18 来源图依次标“当前概率”“×条件概率”“贡献”“相加后的概率”。箭头等宽，明确不以粗细编码概率。
- 柱长、路径、标签和读数都由同一数学模型产生；不使用预设画面或视觉插值伪造概率递推。
- Markdown 正文沿用 `$...$`、`$$...$$` 和现有 MathJax。简单动态数值用语义 HTML/SVG，不新增公式运行库。
- 需要显示矩阵时使用 MathMatrix 二维网格与行序读法；列向量传 `[[x],[y]]`。不是每个图都必须附矩阵。
- 理论恒等式用 `=`；舍入用 `≈`。根号、分数、上下标和转置保持规范。有限小数只在显示边界格式化，不反向输入模型。
- 任何输入裁剪或归一化都必须有数学依据并明确说明。当前模型拒绝非法概率、矩阵、时刻及退化协方差，不静默修补。

## 5. 颜色、图形、坐标与概率尺度

沿用局部 `visualizations.css`：主要对象绿 `#226451 / #86d4b7`，第二来源/构造蓝 `#3b65a0 / #a3c4f5`，基或方向棕 `#855224 / #edbd84`，参考轴灰 `#707a81 / #99a4ac`。颜色含义在局部说明；名称、线型和数值使读者不必只靠辨色。

- 几何图保持横纵等比例；参数比较固定坐标范围，不能靠缩放坐标制造变化。
- 轴标变量与单位；方差 m²、标准差和半轴 m 不混用。
- 概率条轨道统一代表 0—100%，两地分量和为 1。平稳虚线位于同一概率尺度；不能随当前最大值自动缩放。
- 离散 k 只显示合法整数。周期图不添加不存在的中间时刻；未绘制的无限未来由正文结论解释。
- V14 4.6.2 的标准轮廓是 d_M²=1，主半轴为 √λ；4.6.3 交互仅画已知二维 Gaussian 的 95% 轮廓，s=−2log(0.05)，主半轴 √(sλ)。不同时叠两层来增加当前任务负担。
- 95% 图的点线框半宽为 √s σx、√s σy，不能直接标成 σx、σy。固定框只是轮廓的坐标投影范围，不是另外一个 95% 概率矩形，也不是边缘的 ±1σ 区间。
- 标准二维 Gaussian 区域 d_M²≤1 仅约 39.35%，不是 68.27%。覆盖率需要分布及已知参数条件；样本代入、均值置信区间与新观测预测区间另行核实，不能套用。
- `covariancePlot` 的概率面板限定 q=0.95；扩大参数前先核坐标范围、退化/圆形边界、标签与测试。随机模拟不是证明；如以后模拟需种子、样本量和抽样误差说明。

## 6. 操作、回退与局部可读性

- 控件只服务当前变化量。V18 固定矩阵与初分布，仅下一步、前进10步、回到k=0；k 上限60，跳步在边界停止。V14 只开放 ρ∈[−0.95,0.95]，可恢复0.50。
- 控件名称直接说操作；不让“下一步”暗中表示乘积、求和和时间推进三种动作。
- 原生控件、至少44px目标、可见焦点、键盘操作和简洁状态播报；不让每个静态公式成为 Tab 停靠点。
- 无 JS 时保留实际图、标注与必要对照。V18 默认概率条及第一/60步文字仍在 SSR 中；来源和周期图本来就是静态的。V14 默认轮廓及概率条件仍在，不显示无效按钮/滑块。
- 不强求回退中重复全部教材。关键严格推导在正文且无 JS 同样可读；回退不应是“请开启 JavaScript”占位符。
- SVG title/desc、marker 和 aria IDs 同页唯一，重复实例给独立前缀。
- 本批无自动播放，无动画依赖。未来确需播放时另加暂停、重播、进度和减少运动支持。

## 7. 手机、主题与可访问性

- 实测桌面、约390px手机、约320px窄屏、浅/深色。记录实际 CSS innerWidth，而非只抄 viewport 设置；浏览器缩放可能改变两者关系。
- 图形在控件和必要固定条件之后尽早出现。核心读图不依赖放大、横滚或打开多个详情。
- 图内字按实际缩放计算；目标最低约12px，主要说明用14—15px HTML。标签不能压到曲线、刻度或彼此重叠。
- 文字目标对比度4.5:1，必要描边3:1。彩色元素配合名称/线型；浅深色都需实际查看。
- 矩阵不撑宽页面；确实需要的大表仅表内滚动，但优先判断表是否属于当前图的任务。本轮 V18/V14交互无表。
- 检查语义和键盘不等于做过屏幕阅读器听读；视口模拟不等于物理手机。打印分页与 Safari/Firefox 等未验证范围要如实记录。

## 8. 数学和工程门禁

```sh
npm run test:visualizations
npm run figures:check
npm run docs:build
npm run check:visualization-pages
git diff --check
```

- 保留概率守恒、列方向、平稳解、周期及单位矩阵反例、协方差正定性、特征方程、投影极值与概率积分等数学不变量。
- UI 变化时区分旧结构专属断言与数学约束。删除三阶段导航后改测真实时间控件，不再测试不存在的阶段；不能顺便删除概率递推的约束。
- SVG检查验证真实坐标、标注和输出一致性；`figures:check` 只读。新增运行时生成 SVG 要在 SSR 中验证实际几何/数据，不因不是独立资产文件就跳过。
- 页面检查读实际构建HTML：V18两路径的三类概率、结果、柱长、平稳标记、周期柱；V14实际路径、单一轮廓、概率条件；所有静态回退与实例ID。
- 对浮点使用与误差来源相符的容差，不把0.19999999999999996当作违反概率模型，也不为通过测试修改内部精度。
- Pages工作流仍是数学→SVG→单次构建→页面检查，失败阻止上传和部署。PR仅验证，不上传Pages制品、不部署；不绕过门禁。

## 9. 最小交付与验收

1. 记录原文位置、一个主要问题、最简方案、固定/变化量和最可能的误解。列出交给正文的内容，确认正文确实包含它。
2. 实现静态可读结果，再加有明确增量的操作；不引入无关依赖或通用框架。
3. 数学与真实输出一致，保留符号、来源和知识范围；确认删的是重复 UI，而非唯一的知识解释。
4. 模拟首次看图、预测、操作、观察和联系正文；不读长操作说明也应能开始。
5. 检查两主题、手机/桌面、边界、重置、键盘、回退、控制台、公式和锚点。
6. 运行门禁，保存代表性的前后截图及实际尺寸。对图形/信息差异说明教学理由，不能用“高度减少”代替教学分析。
7. 做第二遍批判性检查，发现误导、重复或无用功能直接修复。报告真实学生试学、辅助技术等未验证边界。
8. 更新建设记录并推送当前审阅分支；人工确认后才合并发布。V02/V26等后续内容沿此流程另行开发。

## 10. V1.0全章实施后的补充规范

- **固定对照优先。** V24用0°/最优/90°三个方向；V23三步正交/缩放图与截断图分到6.1.2/6.1.3；V28前向与反向两幅图；V29窗口与重叠梯度分到两个小节。固定帧已能显示关系时不追加控制器。
- **保留可识别标记。** 仅旋转单位圆，轮廓看起来不动；V23携带原标准基的像，使方向改变可见。两个像真正重合时合并文字并解释，不用偏移点假装仍可区分。
- **显示采样也属于数学正确性。** V22小奇异方向在λ≈0变化很快，等间隔粗网格会扭曲半衰位置；必须按曲率加密，并核验特征点。曲线来自正确公式仍可能被错误采样教错。
- **几何与统计坐标分开。** 几何投影、等损失圆、协方差映射保持同单位等比例；密度/频谱趋势不必强作正方形，但需明确单位和归一。位置与速度不能因为都是状态分量，就在等单位地图画椭圆。
- **过程完整可追溯。** V26补充的上一时刻P、F、Q在正文给出，并展开负交叉项；组件不重塞矩阵。只显示边缘尺度时不能要求读者猜图中隐藏的相关项。
- **每种量单独标模型。** V19网格、球占立方体、均匀球壳、Gaussian距离不共享无条件“高维概率”标签；V16理论平稳谱、有限实现、RW时刻方差分别呈现。
- **原图不能凭文件名复用。** 核对KDE实际核协方差、互谱共轭顺序、数据时间索引、随机初始化/归一化和概率尺度。W01—W08处理见V1.0记录；来源不明就保留限制。
- **标注按真实渲染审查。** 本轮逐章扫描图内文字越界/文字重叠，实际发现SVD截断后两个标签重合并修复；DOM检查不能发现所有曲线遮挡，仍需看代表截图。记录真实CSS视口，不只写设备名称。
- **薄复用层。** 新静态图只通过ScienceFigure与catalog渲染，确定性模型在full-math；只为固定Kalman步骤写状态组件。新增依赖、通用矩阵编辑、3D或浏览器训练不是默认选项。
- **源与输出同验。** 所有生成SVG有唯一ID及title/desc；检查生成目录与目录记录完全相符。SSR逐项核对原SVG字节与插入位置；数学用解析结果、积分、有限差分和独立信息形式验证，不能只断言自身函数输出。
- **课程修订不绕门禁。** content-integrity按已发布基线保护标题、公式和原正文；确需修正数学时记录理由并有意识更新基线/审查规则，不能为通过CI跳过内容检查。

本轮全量建设已获用户明确授权在全部验收通过后合并发布，因此第9节第8项的人工确认是默认试点工作流；本次按该授权执行最终PR、CI、合并和线上核验。后续更新按其具体授权与仓库保护规则处理。
