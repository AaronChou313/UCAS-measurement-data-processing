# 系统学习笔记：阅读指南与统一符号

## 1. 这套笔记覆盖什么

本套笔记按原课程六章组织，将课件里分散的定义、推导、图示、算法、程序概念和简短提及重新排成学习顺序。**第 01—08 次课以当前 2026 年 PDF 为主，第 09—14 次课以完整的 2025 年 PDF 为主。**去年前八课中的相关补充也保留，并注明来源。页码均指 PDF 物理页码。

上一版知识点清单覆盖了主要框架，但漏列了一些图表、程序和补充推导中的细项，不能据此直接承诺内容完整。本次已补列，并把清单条目链接到笔记小节；原页与笔记的对应范围见[资料覆盖核对](07_资料覆盖核对.md)。这里的“覆盖”指知识内容的收纳与解释，不是逐字复制每页 PPT，也不是对今年尚未发布课件或考试范围的预测。

**可以把本套笔记作为当前资料范围内系统自学和复习的主线。**自学时仍需完成例题、推导和程序实验，不能只看完文字就认为掌握。考试前应再核对老师最终范围、课堂补充和后续 2026 课件；目前不存在证据证明今年后六课与去年完全相同。

## 3. 统一符号

### 3.1 数据与线性代数

| 符号 | 固定含义 |
|---|---|
| $n$ | 观测／样本数 |
| $p$ | 模型参数个数，含截距；另有说明时才改变 |
| $d$ | 随机向量或特征的维数 |
| $\mathbf x,\mathbf y,\boldsymbol\beta$ | 列向量；粗体表示向量，不表示随机性 |
| $X\in\mathbb R^{n\times p}$ | 回归设计矩阵，行是观测，列是基函数／参数 |
| $D\in\mathbb R^{n\times d}$ | 数据矩阵，行是样本，列是特征或空间位置 |
| $A$ | 一般线性变换矩阵 |
| $I,\mathbf1$ | 单位矩阵、全一列向量 |
| $A^{\mathsf T},A^*$ | 实矩阵转置、复矩阵共轭转置 |
| $A^+$ | Moore–Penrose 广义逆 |
| $\hat{\boldsymbol\beta}$ | 参数估计量／代入数据后的估计值，按上下文区分 |
| $\hat{\mathbf y},\mathbf e$ | 拟合值及残差；固定 $\mathbf e=\mathbf y-\hat{\mathbf y}$ |
| $\boldsymbol\varepsilon$ | 观测模型中的真实随机误差，通常不可直接知道 |
| $U\Sigma V^{\mathsf T}$ | 实矩阵 SVD；奇异值降序且非负 |

### 3.2 统计与不确定性

| 符号 | 固定含义 |
|---|---|
| $\mu,\sigma^2,\sigma$ | 总体均值、方差、标准差 |
| $\bar x,s^2,s$ | 样本均值、分母为 $n-1$ 的样本方差、样本标准差 |
| $m_2$ | 分母为 $n$ 的二阶样本中心矩，避免与 $s^2$ 混用 |
| $C$ | 协方差矩阵；$C_\varepsilon$、$C_\beta$ 标明对象 |
| $W$ | LS 权阵，绝对权通常为 $C_\varepsilon^{-1}$ |
| $\rho,r$ | 总体相关系数、样本相关系数 |
| $\lambda_j$ | 特征值；$\lambda$ 单独用于正则强度时有明确声明 |
| $\alpha$ | 显著水平，置信水平为 $1-\alpha$ |
| $z_q,t_{q,\nu},\chi^2_{q,\nu},F_{q,\nu_1,\nu_2}$ | 对应分布的**下尾累计概率**为 $q$ 的分位数 |
| $\nu$ | 自由度；标准误写作 $\operatorname{SE}$ |

标准差描述随机量本身的散布，标准误描述估计量的抽样散布。它们都与被估对象同单位；方差和协方差的单位分别是单位的平方、两种单位的乘积。

### 3.3 时间、频谱和状态

| 符号 | 固定含义 |
|---|---|
| $\Delta t,f_s,T_{\rm rec}$ | 采样间隔、采样率 $1/\Delta t$、DFT 记录时长 $N\Delta t$ |
| $f,\omega$ | 周期／单位时间、弧度／单位时间；$\omega=2\pi f$ |
| $\mathcal F\{x\}(f)$ | 连续 Fourier 变换，正向指数为 $-i2\pi ft$ |
| $\tilde x_k$ | 未归一化正向 DFT；逆 DFT 含 $1/N$ |
| $S_{xx},S_{xy}$ | 自功率谱密度、互功率谱密度 |
| $\hat{\mathbf x}_{k\mid k-1},\hat{\mathbf x}_{k\mid k}$ | Kalman 预测状态、更新状态 |
| $P,Q,R$ | 状态误差、过程噪声、观测噪声的协方差 |
| $F,G,H,K$ | 状态转移、控制输入、观测、Kalman 增益矩阵 |

符号允许在**明确的新场景**中重用，例如神经网络权重 $W^{(\ell)}$ 与 LS 权阵 $W$；小节开始会重新声明对象和尺寸。所有角度进入三角函数前用弧度；图中可标度数，但要明确转换。

## 4. 学习与复习检查

1. 第一遍：看定义、模型假设、核心公式和直观解释，完成每章的小例题。
2. 第二遍：遮住推导重做，检查维度、单位、极限情形和适用条件。
3. 程序实践：检查输入形状、随机种子、噪声标准差、单位、归一化和评估数据划分；至少用一种解析结果或重建恒等式验算。
4. 考前：按[知识点清单](../全课程知识点清单.md)逐条勾选；“会”应指能定义、计算、解释和识别误用。然后重做[当前作业](../01_逐课作业原题.md)，核对[答案](../02_逐课作业解答.md)。

课件中的历史故事和应用名称也收纳，但不把它们扩写成另一本教材；其作用是理解方法的产生背景和应用对象。原始作业的数值、措辞和版本仍以原题页为准。
