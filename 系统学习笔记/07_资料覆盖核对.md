## 5. 需要带条件阅读的课件表述

| 表述风险 | 笔记采用的解释 |
|---|---|
| 任意矩阵都可用特征向量换基 | 需要完整独立特征向量；任意矩阵有 SVD |
| 行列式大于零就正定 | 对称二维还需正主元／正特征值；一般不能只看行列式 |
| 协方差特征值就是半轴 | 特征值是方差，半轴需平方根及概率尺度 |
| 任意点云可由 Gaussian 线性变换生成 | 只保证匹配协方差，Gaussian 变换仍 Gaussian，不能产生任意分布 |
| 一维 2σ 与二维椭圆覆盖率相同 | 二维用 χ²₂，平方阈值 4 覆盖约 86.47% |
| 高维球体体积一般只含一个 √π | 一般公式是 π 的 d/2 次幂，低维核验 |
| 高维最小距离必趋零 | 需规定分布、归一化和极限；一般并非如此 |
| Ridge 对所有系数全局缩放 | 一般沿奇异方向按不同因子收缩 |
| 沿正梯度下降 | 梯度是上升方向，最小化使用负梯度 |
| 外部过程噪声总用 F 投影 | 依据噪声驱动矩阵，连续模型使用协方差积分 |
| 插值／零填充增加独立信息 | 改善表示或网格，不新增独立观测 |

纠正用于避免学习错误；原题措辞与数值保留在[作业原题](../01_逐课作业原题.md)，答案另说明解释约定。
