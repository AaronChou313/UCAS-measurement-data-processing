## 第三层：先统一PCA的形状

<a id="sec-05"></a>
### 三个数量不是一回事

本单元重复强调：$n_t$或`n_samples`是观测数量，$n_x$或`n_features`是变量数量，$k$是保留的成分数量。采用样本按行：

$$
X\in\mathbb R^{n\times d},\qquad
C=\frac{1}{n-1}X_c^{\mathsf T}X_c.
$$

这里$X_c$为中心化数据。课件一些页用$1/n$归一化，另一些库输出使用$n-1$；方向不会因统一标量改变，但特征值大小会变。比较程序结果前必须对齐约定。[原课件P2–4](../appendices/L14_原页对照.md#p002)

若$C$的前$k$个单位特征向量组成$V_k\in\mathbb R^{d\times k}$：

$$
T= X_c V_k\in\mathbb R^{n\times k},\qquad
\hat X_c=T V_k^{\mathsf T}.
$$

保留所有有效方向可恢复输入的中心化数据；只保留部分方向得到主要变化的重建。最后还要反做标准化/加回均值，才能回到原始单位。[原课件P4–6](../appendices/L14_原页对照.md#p004)

<a id="sec-06"></a>
### 协方差、相关矩阵与单位

课件指出：协方差方法让方差大的变量具有更大影响；相关矩阵方法等价于先按各变量尺度标准化。不同单位或数量级差异很大时，两种选择会改变提取的模式，必须记录选择理由。[原课件P5](../appendices/L14_原页对照.md#p005)

课件还展示将PC除以$\sqrt{\lambda_k}$、EOF乘以$\sqrt{\lambda_k}$的重新归一化。乘积不变，但PC方差与EOF单位改变。比较两张EOF图以前，应先问是否使用同一归一化。[原课件P6](../appendices/L14_原页对照.md#p006)

<a id="sec-07"></a>
## 第三层：statsmodels PCA输出对应什么

第7—13页从`stock.txt`读入数据，再使用`statsmodels.multivariate.pca.PCA`。课件将输出分成：

- `eigenvals`：各成分对应的特征值；归一化后可得解释方差比例。
- `loadings`：方向/载荷；其矩阵朝向要按实际输出检查。
- `factors`或`scores`：每个样本的成分坐标。
- `projection`与`project(k)`：用全部或指定数量成分恢复数据。

课件默认参数包含标准化与去均值，因此不能把默认结果直接与“只中心化”的手推结果比较。第11页属性说明与第9、13页注释的部分形状写法不完全一致，笔记不替接口猜方向；应对照`shape`与数学乘法检查。[原课件P7–13](../appendices/L14_原页对照.md#p007)

程序阅读顺序：**读取数据 → 指明预处理 → 计算PCA → 查看特征值谱 → 看方向与时间系数 → 重建 → 比较原数据。**

## 第三层：sklearn接口与几何检查

<a id="sec-09"></a>
### fit、predict和transform各自的对象

课件第14—16页将估计器与变换器分开：拟合模型用`fit`，预测任务用`predict`，数据变换用`transform`。PCA的`fit`学习方向，`transform`计算样本在这些方向的坐标；它不是预测另一个监督标签。[原课件P14–16](../appendices/L14_原页对照.md#p014)

<a id="sec-10"></a>
### 股票数据的标准化、协方差与马氏距离

第17—22页先用`StandardScaler`标准化，再估计协方差并绘制距离等值线。课件代码对`mahalanobis`结果开平方，因为该调用返回的是平方距离；“变量名包含dist”不保证已经是距离本身。[原课件P17–22](../appendices/L14_原页对照.md#p017)

PCA方向在课件代码中取`pca.components_.T`，随后：

$$
T=X_cV,\qquad P_1=v_1v_1^{\mathsf T},\qquad
X_{(1)}=X_cP_1.
$$

**成分坐标$X_cV$**与**投影回原空间$X_cv_1v_1^{\mathsf T}$**是两种不同输出：前者是新坐标，后者仍具有原变量数量。第19—22页的几何图是理解这一区别的关键。[原课件P18–22](../appendices/L14_原页对照.md#p018)

<a id="sec-11"></a>
### SST：从长表组织成时空矩阵

课件输入`pacific_sst_test_data.txt`包含经度、纬度、时间、海温，给出网格规模$(180,60,29)$。空间网格展成变量维，时间作为样本维后，PCA输出的每个方向可以恢复为空间图，成分坐标则沿时间画曲线。[原课件P23–28](../appendices/L14_原页对照.md#p023)

这里最容易出错的是`reshape`：必须依据原文件的时间、经纬度排序确定轴顺序，而不是看到总元素数相等就随意重排。时间点、空间坐标、缺测掩膜及展平顺序应作为数据处理记录保存。课件打印13个成分的结果只是示例，不能预设你的数据也有相同解释方差比例。

<a id="sec-12"></a>
### ICA程序输出

第29—31页采用`FastICA(n_components=13)`。`transform`得到独立成分时间系数；`mixing_`与`components_`分别对应混合与解混相关矩阵。ICA存在符号、顺序和尺度约定，比较空间图时要对齐，而不是要求第1成分逐数字等于PCA第1成分。[原课件P29–31](../appendices/L14_原页对照.md#p029)

本单元的图像显示怎么读程序输出；ICA的独立性假设、白化和熵仍回到第11课复习，不能用一次函数成功返回作为分离成功的充分证据。

## 第三层：回归程序与统计解释

<a id="sec-14"></a>
### 一元、多元与网格预测

课件用$y=1+0.5x+\varepsilon$做一元示例，再用$y=1-3x_1+2x_2+\varepsilon$做多元示例。`LinearRegression`拟合后提取`coef_`与`intercept_`，用`predict`在已组织好的特征行上预测。[原课件P32–38](../appendices/L14_原页对照.md#p032)

多元网格预测的流程：生成$x_1,x_2$网格 → 展平为两个等长列 → 按训练时的列顺序组成预测矩阵 → 预测 → 恢复网格形状。第38页的网格shape注释需与实际`meshgrid`和轴顺序核对，不能只按画图方向猜。

<a id="sec-15"></a>
### statsmodels OLS的统计输出

第39—41页用`statsmodels`输出系数、标准误、$t$、$p$、区间和$R^2$。这些名称应与第05课的推导一一对应。尤其注意设计矩阵的常数列：不同调用是否默认带截距必须从课件代码构建方式看，不能把不同库的默认行为视为一样。[原课件P39–41](../appendices/L14_原页对照.md#p039)

<a id="sec-16"></a>
## 第三层：Bootstrap怎样得到区间

<a id="sec-17"></a>
### 对相关系数做放回抽样

课件从原样本反复有放回抽样，每次形成同样规模的新样本，计算相关系数，再取这些相关系数的经验分位数。95%双侧区间对应2.5%与97.5%的分位点。[原课件P42–44](../appendices/L14_原页对照.md#p042)

对成对数据$(x_i,y_i)$，抽样单位是**整对记录**：两列使用相同索引。分别打乱两列会改变关联关系，不是原有相关系数的同一Bootstrap实验。

<a id="sec-18"></a>
### 与均值Bootstrap比较

第45页对均值重复同样思想：被重算的统计量从相关系数变成均值。Bootstrap来自当前样本的经验分布；它与第06课按假定概率模型重新生成样本的Monte Carlo相联系，但不是同一个抽样来源。[原课件P43–45](../appendices/L14_原页对照.md#p043)

课件未在这里展开所有时间相关数据的Bootstrap方案，因此不要自动把独立记录重采样法用于强时间自相关序列并宣称区间有效。

## 第三层：多项式、Ridge与Lasso

<a id="sec-20"></a>
### 先生成特征，再进行线性回归

课件以$\cos(2\pi x/10)$在$x\in[0,4]$上的短片段，加上不同噪声构造例子。`PolynomialFeatures`生成$1,x,x^2,\ldots$等特征，后面的线性回归仍然对系数线性。这里呼应第04课“函数对$x$弯曲，不等于对参数非线性”。[原课件P46–49](../appendices/L14_原页对照.md#p046)

<a id="sec-21"></a>
### Ridge比较

第50—57页采用8阶多项式，改变噪声以及惩罚因子：

$$
\alpha\in\{10^{-5},10^{-4},0.01,1,10,100\}.
$$

课件展示的不只是拟合曲线，还包括各阶系数大小。增加惩罚会限制系数，但过强的惩罚也可能抹掉有意义变化；零噪声、0.3噪声、1.2噪声的结果不能混为一组。[原课件P50–57](../appendices/L14_原页对照.md#p050)

<a id="sec-22"></a>
### Lasso比较

第58—65页在相近设置下换成Lasso，考察部分系数被压至0与曲线形态变化。联系第09课：L2与L1惩罚具有不同几何结构，前者收缩、后者可能稀疏；“更稀疏”不自动意味着拟合和预测都更好。[原课件P58–65](../appendices/L14_原页对照.md#p058)

课件特意提示不同图的纵轴尺度。比较系数曲线时，必须同时看坐标轴、输入缩放、惩罚强度和损失定义；不能只比较线条高低。程序中的alpha与前面统计显著性水平只是同名符号，含义不同。[原课件P57](../appendices/L14_原页对照.md#p057) [原课件P65](../appendices/L14_原页对照.md#p065)

## 第四层：把综合实践连成完整工作流

**明确数据布局 → 记录预处理 → 用理论定位算法输入输出 → 拟合 → 提取参数或成分 → 恢复到原单位与原坐标 → 检查残差、区间、解释方差及图形 → 改变设置做对照。**

## 课后作业：题目、数据与提交要求

<a id="sec-26"></a>
### 选做1：梯度下降回归函数化

来源：[原课件P66](../appendices/L14_原页对照.md#p066)。将一元/多元线性回归梯度下降示例改写成函数，原题接口为：

```text
fun_name(X, y, theta, iters, epsilon, rmmean=0, normal=0)
```

输出最终`theta`。

- `epsilon`：停止迭代标准，例如两次参数结果差异0.0001；多参数如何判停需要自己定义并说明。
- `rmmean=0`不去均值，`rmmean=1`对X和y去均值后回归。
- `normal=0`不归一化，`normal=1`归一化，并思考其目的。

<a id="sec-27"></a>
### 选做2：Monte Carlo参数精度

来源：[原课件P66](../appendices/L14_原页对照.md#p066)。思考并尽量编程，用Monte Carlo给出梯度下降求得参数的精度估计；集成到选做1中。

增加默认参数`precision95=0`，关闭时不给出95%置信水平的精度，打开时给出；输出增加`pre95`。

**原题符号不一致：**前面写`precision95`，后面写`precision=1`。这应在实现接口中统一，但本资料不悄悄替换原题。
