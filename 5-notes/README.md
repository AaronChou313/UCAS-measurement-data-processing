## 从哪里开始

先打开[总大纲](00_总大纲.md)，只看六章地图和每次课的主题。然后进入某一课，按以下顺序阅读：

1. **第一层：本课全景与课时大纲**——知道这次课在课程中的位置、包含哪些原章节。
2. **第二层：知识树**——把本课展开为小节和知识点，先看层级，不急于推公式。
3. **第三层：知识点正文**——读概念、符号、公式、核心推导和课件例子；必要时打开原页。
4. **第四层：串联与自检**——用自己的话说明各部分为何相连，再做课后作业。

第01、02课对应你已经上过的内容；你已确认第02次课堂讲完点估计、最大似然和区间估计。其余课时边界按课件编排，不保证当前老师每次课逐页讲完。文件名中的2025日期是源课件日期，不是当前学期课表。总纲按13次常规课各3学时、最后实践/答疑单元1学时处理，共40学时。

## 如何打开与保存

请**解压整个资料包**，保留目录结构，再用支持Markdown及LaTeX的本地笔记软件打开`00_总大纲.md`。本包不依赖特定软件或账户；不同软件对HTML目录折叠、PDF页码跳转的支持可能有差别。

正文行内公式使用`$...$`，独立公式使用`$$...$$`。目录有明确的锚点；图片与其他文件使用相对路径。单独拷贝一份笔记到别处会使图片、原页及跨课链接失效，应连同整个文件夹移动。PDF链接中的`#page=数字`在不支持定位的阅读器里可能只打开PDF，仍可按标注页码手动翻页。

**图片全部为完整页面，不是局部裁图。**主笔记只嵌入与当前讲解相关的页面；附录则逐页保留全部1542页，包含原始图、表、公式、代码及原题。小字或公式仍看不清时，打开对应原PDF放大。

## 哪些是课件内容，哪些是学习辅助

- **来源正文**：保留原章/节编号与术语，按理解顺序重新组织；不是逐页逐字转录。公式的中间代数步骤用于展开课件表达，并不替代原页。
- **课后作业**：保留原题要求、子问题、明确给出的数值、文件名和选做标识；原题图在每课作业末尾完整附上。没有擅自提供整套作业答案。
- **整理者自检/建议**：为复习而归纳的问题、阅读顺序和记录模板，不是老师额外布置的必交内容。
- **待核对事项**：把原文内部的记号差异、缺少的条件和疑似笔误单独列出。它不是经外部文献逐项验证的权威勘误表。不要把课件中的经验阈值或某个算例结论当作普遍保证。

所有来源页碼按**每份PDF独立计数的物理页码**，不是某章内手写编号。原页及原PDF保持原样，笔记里的说明不会覆盖原始表述。

## 作业与程序边界

[作业总索引](01_作业总索引.md)可以跳到各课的原题整理。第10课未发现独立标为作业的题页；不把其他课程的题移来补足。第13课MNIST延伸与第14单元的选做标识保留。

## 建议的学习记录

每完成一小节，记下：**问题是什么 → 输入/输出是什么 → 条件和公式是什么 → 与前一节有什么联系 → 还有哪里未理解**。完成作业时，再加入数据来源、程序参数、图表与结果解释。提交平台、截止日期和本学期文件命名要求以老师通知为准。
