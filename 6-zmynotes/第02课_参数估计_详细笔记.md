# 0. 第二课到底在解决什么问题？

这一课的核心问题只有一句话：

\[
\boxed{
\text{如何利用有限样本，推断未知总体的参数？}
}
\]

整个知识链可以先记成：

```text
总体随机变量 X
    ↓
总体具有某种概率分布 F(x;θ)
    ↓
参数 θ 未知
    ↓
从总体抽样 X1,...,Xn
    ↓
得到观测值 x1,...,xn
    ↓
用样本估计 θ
    │
    ├─ 点估计
    │   ├─ 矩估计
    │   └─ 最大似然估计 MLE
    │
    ├─ 评价估计量
    │   ├─ 一致性
    │   ├─ 无偏性
    │   ├─ 方差
    │   └─ MSE
    │
    └─ 区间估计
        └─ 置信区间
```

# 1. 先区分描述统计和推断统计

## 1.1 描述统计

假设手里有一组数据：

\[
x_1,x_2,\ldots,x_n
\]

描述统计只回答：

> 这批数据自身是什么样？

例如计算：

- 样本均值；
- 样本方差；
- 中位数；
- 分位数；
- 直方图。

它不一定试图推广到更大的总体。

## 1.2 推断统计

推断统计回答：

> 我手里只有有限样本，但我真正想知道的是背后的总体。

例如：

- 总体均值是多少？
- 总体方差是多少？
- 某个模型参数是多少？
- 参数大概落在哪个范围？

第二课主要属于：

\[
\boxed{\text{推断统计}}
\]

# 2. 整套符号关系：先弄清楚“谁是谁”

这是理解后面所有公式的基础。

## 2.1 总体随机变量 \(X\)

记：

\[
X\sim F(\theta)
\]

表示随机变量 \(X\) 服从某个分布，分布参数为 \(\theta\)。

例如：

\[
X\sim N(\mu,\sigma^2)
\]

其中：

- \(X\)：随机变量；
- \(\mu\)：总体均值；
- \(\sigma^2\)：总体方差；
- \(\mu,\sigma^2\) 是固定但未知的参数。

## 2.2 随机样本 \(X_1,\ldots,X_n\)

从总体独立抽样 \(n\) 次：

\[
X_1,X_2,\ldots,X_n
\]

在通常的独立同分布抽样假设下：

\[
X_i\sim X
\]

因此：

\[
E(X_i)=E(X)=\mu
\]

\[
Var(X_i)=Var(X)=\sigma^2
\]

注意：此时 \(X_i\) 仍然是随机变量，因为还没真正抽到具体数值。

## 2.3 样本观测值 \(x_i\)

真正执行一次抽样以后，我们把实际得到的数字记为：

\[
x_1,x_2,\ldots,x_n
\]

所以：

\[
\boxed{
X_i=\text{抽样前的随机变量}
}
\]

\[
\boxed{
x_i=\text{抽样后得到的具体数}
}
\]

## 2.4 样本均值 \(\bar X\) 与 \(\bar x\)

抽样之前：

\[
\bar X
=
\frac1n\sum_{i=1}^{n}X_i
\]

由于每个 \(X_i\) 都随机，所以 \(\bar X\) 也是随机变量。

真正得到样本以后：

\[
\bar x
=
\frac1n\sum_{i=1}^{n}x_i
\]

就是一个具体数字。

因此：

\[
\boxed{
\bar X=\text{样本均值这个统计量/估计量}
}
\]

\[
\boxed{
\bar x=\text{本次样本均值的具体数值}
}
\]

## 2.5 参数、估计量、估计值

真实但未知参数：

\[
\theta
\]

根据随机样本构造：

\[
\hat\theta
=
g(X_1,\ldots,X_n)
\]

这是**估计量**，因为它仍然是随机变量。

一次具体抽样后：

\[
\hat\theta
=
g(x_1,\ldots,x_n)
\]

得到一个具体数字，这叫**估计值**。

最重要的三层关系：

\[
\boxed{
\text{总体参数（固定未知）}
\neq
\text{估计量（随机变量）}
\neq
\text{估计值（具体数字）}
}
\]

# 3. PDF 和 CDF 放在这里应该怎么理解？

PPT先讲PDF/CDF，会让人感觉和后面的估计突然断开。实际上它们是后续参数估计使用的“概率语言”。

## 3.1 PDF：概率密度函数

对连续随机变量：

\[
f(x)
\]

描述概率密度。

注意：

\[
f(x)
\]

本身一般不是“点概率”。

区间概率为：

\[
P(a<X<b)
=
\int_a^b f(x)\,dx
\]

所以PDF更准确地描述：

> 概率在不同位置附近分布得有多密。

## 3.2 CDF：累积分布函数

定义：

\[
F(x)
=
P(X\le x)
\]

连续情形下：

\[
F(x)
=
\int_{-\infty}^{x}f(t)\,dt
\]

所以：

\[
P(a<X\le b)
=
F(b)-F(a)
\]

## 3.3 为什么后面估计还需要PDF/CDF？

因为参数估计通常写成：

\[
f(x;\theta)
\quad\text{或}\quad
F(x;\theta)
\]

意思是：

> 分布形式大体知道，但其中参数 \(\theta\) 不知道。

例如：

\[
X\sim N(\mu,\sigma^2)
\]

就是已经选择了正态分布族，但还需要估：

\[
\mu,\sigma^2
\]

特别是MLE会直接使用：

\[
L(\theta)
=
\prod_i f(x_i;\theta)
\]

所以PDF/CDF不是独立插入的知识，只是PPT把它们放得太早，没有先解释“为什么以后要用”。

# 4. 数学期望：总体分布的理论中心

## 4.1 离散随机变量

若：

\[
P(X=x_i)=p_i
\]

则：

\[
E(X)
=
\sum_i x_i p_i
\]

可以理解成：

\[
\boxed{
\text{所有可能值按其发生概率做加权平均}
}
\]

## 4.2 连续随机变量

连续情况下：

\[
E(X)
=
\int_{-\infty}^{\infty}
x f(x)\,dx
\]

本质没有变化，只是“求和”变成积分。

因此：

\[
\boxed{
E(X)\text{ 是总体概率分布自身的理论均值}
}
\]

常记为：

\[
E(X)=\mu
\]

而样本均值：

\[
\bar x
\]

只是当前有限样本的平均数。

不要混淆：

\[
\boxed{
E(X)=\mu
\neq
\bar x
}
\]

虽然我们经常用：

\[
\bar X
\]

去估计 \(\mu\)。

# 5. 矩到底是什么？

如果只从数据处理数学角度理解，可以暂时忽略PPT中的质心、力矩、转动惯量等物理类比。

最实用的理解是：

\[
\boxed{
\text{矩是一族用数字概括概率分布特征的方法}
}
\]

# 6. 原点矩

\(k\) 阶原点矩：

\[
\boxed{
m_k'
=
E(X^k)
}
\]

注意不要把它机械叫做“距离原点的 \(k\) 阶平均距离”，因为奇数次幂保留正负号。

更准确地说：

> 先把 \(X\) 做 \(k\) 次幂，再取总体平均。

## 6.1 一阶原点矩

\[
E(X)=\mu
\]

也就是总体均值。

因此一阶矩最直观地描述：

\[
\boxed{\text{分布中心大概在哪里}}
\]

## 6.2 二阶原点矩

\[
E(X^2)
\]

它不是方差。

它同时受：

- 分布中心位置；
- 分布离散程度；

影响。

---

# 7. 中心矩

为了只关注“相对自身中心的形状”，先减去总体均值：

\[
X-\mu
\]

\(k\) 阶中心矩定义：

\[
\boxed{
\mu_k
=
E[(X-\mu)^k]
}
\]

## 7.1 一阶中心矩

\[
E(X-\mu)=0
\]

所以没有额外信息。

## 7.2 二阶中心矩：方差

\[
\boxed{
Var(X)
=
E[(X-\mu)^2]
}
\]

这就是总体方差。

它表示：

\[
\boxed{
\text{随机变量相对于总体中心的平均平方偏离程度}
}
\]

---

# 8. 为什么方差要平方？

如果直接平均偏差：

\[
E(X-\mu)
\]

正负会抵消，而且结果永远为0：

\[
E(X-\mu)
=
E(X)-\mu
=
0
\]

所以必须让正负偏差不互相抵消。

统计学大量采用平方，是因为平方：

- 始终非负；
- 对大偏差惩罚更强；
- 可微，便于求导和最优化；
- 与矩阵、最小二乘、协方差、PCA等工具天然兼容。

因此：

\[
\boxed{
\text{方差}=
\text{到总体均值的平均平方距离}
}
\]

## 8.1 方差的等价公式

展开：

\[
Var(X)
=
E[(X-\mu)^2]
\]

得到：

\[
\boxed{
Var(X)
=
E(X^2)-[E(X)]^2
}
\]

因此：

\[
E(X^2)
=
Var(X)+[E(X)]^2
\]

只有当：

\[
E(X)=0
\]

时：

\[
E(X^2)=Var(X)
\]

---

# 9. 三阶、四阶中心矩

## 9.1 三阶中心矩与偏度

三次方保留正负：

\[
E[(X-\mu)^3]
\]

因此可以反映左右不对称。

常见偏度会进一步标准化：

\[
\text{Skewness}
=
\frac{E[(X-\mu)^3]}{\sigma^3}
\]

所以：

- 正偏：右尾较长；
- 负偏：左尾较长；
- 偏度0不一定保证严格对称。

## 9.2 四阶中心矩与峰度

四次方对远离均值的数据特别敏感：

\[
E[(X-\mu)^4]
\]

常用标准化形式：

\[
\frac{E[(X-\mu)^4]}{\sigma^4}
\]

PPT采用“减3”的超额峰度定义，使正态分布的峰度为0。

# 10. 总体矩、样本矩与总体参数不是同一个概念

总体分布具有很多特征，例如：

- 均值；
- 方差；
- 偏度；
- 峰度；
- 各阶矩。

但“总体参数”通常指某个选定概率模型中真正需要确定的参数。

例如：

\[
X\sim N(\mu,\sigma^2)
\]

真正模型参数是：

\[
\mu,\sigma^2
\]

偏度、峰度在选定正态分布后已经由分布决定，并不是额外的自由参数。

因此最好说：

\[
\boxed{
\text{矩是总体统计特征；其中一些矩与模型参数存在对应关系}
}
\]

正是因为这种对应关系，才可以利用样本矩估计参数。

---

# 11. 参数估计到底是什么？

假设：

\[
X\sim f(x;\theta)
\]

分布形式已知，但参数：

\[
\theta
\]

未知。

我们只能得到有限样本：

\[
x_1,\ldots,x_n
\]

然后利用样本推断：

\[
\theta
\]

这就叫：

\[
\boxed{\text{参数估计}}
\]

例如：

\[
X\sim N(\mu,\sigma^2)
\]

已知它是正态分布，但不知道：

\[
\mu,\sigma^2
\]

利用样本估这两个参数，就是参数估计。

---

# 12. 点估计和区间估计

## 12.1 点估计

给未知参数一个具体估计值：

\[
\boxed{
\hat\theta
=
\text{某个由样本计算出的值}
}
\]

例如：

\[
\hat\mu=\bar x=10.37
\]

回答：

> 参数大约是多少？

## 12.2 区间估计

点估计会随样本变化，所以进一步给一个区间：

\[
[L,U]
\]

例如：

\[
[9.9,10.8]
\]

回答：

> 参数可能落在哪个范围？

区间估计的价值是：

\[
\boxed{
\text{量化抽样造成的不确定性}
}
\]

---

# 13. 矩估计：最直接的点估计方法

矩估计的核心：

\[
\boxed{
\text{总体矩}
=
\text{对应样本矩}
}
\]

然后解未知参数。

## 13.1 样本矩

样本 \(k\) 阶原点矩：

\[
m_k
=
\frac1n
\sum_{i=1}^{n}X_i^k
\]

实际观测后：

\[
m_k
=
\frac1n
\sum_{i=1}^{n}x_i^k
\]

## 13.2 正态分布例子

设：

\[
X\sim N(\mu,\sigma^2)
\]

总体一阶原点矩：

\[
E(X)=\mu
\]

样本一阶矩：

\[
m_1=\bar X
\]

令：

\[
\mu=m_1
\]

得到：

\[
\boxed{
\hat\mu_{\text{MOM}}
=
\bar X
}
\]

二阶原点矩：

\[
E(X^2)
=
\mu^2+\sigma^2
\]

样本二阶矩：

\[
m_2
=
\frac1n\sum X_i^2
\]

令：

\[
\mu^2+\sigma^2=m_2
\]

代入 \(\hat\mu=\bar X\)，得到：

\[
\boxed{
\hat\sigma^2_{\text{MOM}}
=
\frac1n\sum_{i=1}^{n}
(X_i-\bar X)^2
}
\]

矩估计的思想不是“样本矩一定就等于总体矩”，而是：

> 用样本矩作为总体矩的近似，再反推出模型参数。

# 14. 最大似然估计 MLE

矩估计利用“矩”；MLE利用的是完整概率模型。

核心问题：

\[
\boxed{
\text{哪一个参数最容易产生我们已经观测到的这组数据？}
}
\]

## 14.1 概率与似然的方向不同

概率：

> 参数固定，问数据出现的可能性。

似然：

> 数据已经固定，问哪个参数最能解释这些数据。

因此：

\[
\boxed{
\text{Probability：固定参数，看数据}
}
\]

\[
\boxed{
\text{Likelihood：固定数据，看参数}
}
\]

## 14.2 似然函数

独立样本时：

\[
\boxed{
L(\theta)
=
\prod_{i=1}^{n}
f(x_i;\theta)
}
\]

MLE选择：

\[
\boxed{
\hat\theta_{\text{MLE}}
=
\arg\max_\theta L(\theta)
}
\]

## 14.3 MLE标准流程

1. 写出概率模型 \(f(x;\theta)\)；
2. 构造似然 \(L(\theta)\)；
3. 取对数：
   \[
   \ell(\theta)=\ln L(\theta)
   \]
4. 对参数求导；
5. 令导数为0；
6. 解参数；
7. 检查是否为最大值。

## 14.4 为什么取对数？

独立样本似然是大量乘法：

\[
L=\prod_i f(x_i;\theta)
\]

取对数后：

\[
\ln L
=
\sum_i\ln f(x_i;\theta)
\]

乘法变加法。

而 \(\ln x\) 单调递增，所以最大值位置不变。

## 14.5 正态总体MLE

若：

\[
X_i\sim N(\mu,\sigma^2)
\]

可以得到：

\[
\boxed{
\hat\mu_{\text{MLE}}
=
\bar X
}
\]

以及：

\[
\boxed{
\hat\sigma^2_{\text{MLE}}
=
\frac1n
\sum_{i=1}^{n}(X_i-\bar X)^2
}
\]

这里MLE结果与矩估计很像，但两者出发点完全不同：

- 矩估计：匹配样本矩和总体矩；
- MLE：最大化当前样本的似然。

---

# 15. 为什么MLE没有统一的最终公式？

MLE有统一的“思想”：

\[
\max_\theta L(\theta)
\]

但没有统一的参数解析式。

原因是不同问题中的：

\[
f(x;\theta)
\]

完全不同。

例如：

- Normal；
- Uniform；
- Exponential；
- Gamma；
- 多参数模型；
- 非独立样本。

都会产生不同似然函数。

所以：

\[
\boxed{
\text{MLE有统一原则，没有统一闭式答案}
}
\]

有些问题能直接求导得到解析解，有些只能用Newton–Raphson等数值方法求解。

---

# 16. MLE不变性原理

若：

\[
\hat\theta
\]

是 \(\theta\) 的MLE，那么在合适条件下：

\[
\boxed{
g(\hat\theta)
}
\]

就是：

\[
g(\theta)
\]

的MLE。

例如已经求出方差：

\[
\hat\sigma^2
\]

想要标准差：

\[
\sigma=\sqrt{\sigma^2}
\]

可以直接：

\[
\boxed{
\hat\sigma
=
\sqrt{\hat\sigma^2}
}
\]

不用重新从头构造一遍似然。

---

# 17. MLE的数值求解与Newton–Raphson

求极大值常需要解：

\[
\frac{d\ell}{d\theta}=0
\]

如果无法解析求解，可以把它看成“找零点”问题：

\[
g(\theta)=0
\]

Newton–Raphson迭代：

\[
\theta_{k+1}
=
\theta_k
-
\frac{g(\theta_k)}{g'(\theta_k)}
\]

这说明高等数学里“求导、Taylor展开、求零点”最终都会进入参数估计。

---

# 18. 经验分布函数 ECDF

MLE通常需要知道分布形式。现实中如果总体分布未知，可以先用样本构造经验分布：

\[
F_n(x)
=
\frac{\#\{X_i\le x\}}{n}
\]

样本越多：

\[
F_n(x)
\]

通常越接近总体CDF。

PPT还提到K-S检验，可用于比较样本经验分布与某个理论分布是否相符。

这一块在第二课中属于“分布未知时怎么办”的补充。

---

# 19. 估计量为什么还要评价？

矩估计、MLE都能给答案，但：

\[
\hat\theta_1,\hat\theta_2
\]

可能不一样。

所以还要问：

- 样本很多时会不会趋近真值？
- 平均来说会不会系统性偏大或偏小？
- 重复抽样时是否稳定？

这就是2.3“参数估计的统计性质”。

---

# 20. 一致性 Consistency

一致性关心：

\[
n\to\infty
\]

时：

\[
\hat\theta_n
\]

是否趋近：

\[
\theta
\]

直觉：

\[
\boxed{
\text{样本越来越多，估计是否越来越接近真值？}
}
\]

一致性是一个“大样本性质”。

---

# 21. 无偏性 Unbiasedness

固定样本量 \(n\)，重复抽样很多次。

如果：

\[
\boxed{
E(\hat\theta)=\theta
}
\]

则 \(\hat\theta\) 是无偏估计量。

偏差定义：

\[
\boxed{
Bias(\hat\theta)
=
E(\hat\theta)-\theta
}
\]

无偏并不是“每次都估得准”。

它表示：

\[
\boxed{
\text{长期重复抽样时，估计值的中心没有系统偏离真值}
}
\]

---

# 22. 样本均值为什么无偏？

因为：

\[
\bar X
=
\frac1n\sum X_i
\]

所以：

\[
E(\bar X)
=
\frac1n\sum E(X_i)
=
\frac1n(n\mu)
=
\mu
\]

因此：

\[
\boxed{
\bar X\text{ 是 }\mu\text{ 的无偏估计量}
}
\]

---

# 23. 总体方差、样本方差和 \(n-1\)

总体方差：

\[
\boxed{
\sigma^2
=
E[(X-\mu)^2]
}
\]

这本身是定义，不涉及“有偏/无偏”。

现实中 \(\mu\) 未知，只能用样本均值 \(\bar X\)。

若直接定义：

\[
\tilde S^2
=
\frac1n
\sum(X_i-\bar X)^2
\]

可以证明：

\[
\boxed{
E(\tilde S^2)
=
\frac{n-1}{n}\sigma^2
}
\]

所以它系统性偏小。

原因可以从分解式理解：

\[
\boxed{
\sum(X_i-\mu)^2
=
\sum(X_i-\bar X)^2
+
n(\bar X-\mu)^2
}
\]

样本均值 \(\bar X\) 是专门由本批样本计算出的中心，因此相对于 \(\bar X\) 的平方偏差天然更小。

为了修正偏差：

\[
\boxed{
S^2
=
\frac1{n-1}
\sum(X_i-\bar X)^2
}
\]

满足：

\[
E(S^2)=\sigma^2
\]

## 23.1 为什么自由度是 \(n-1\)？

残差：

\[
X_i-\bar X
\]

满足：

\[
\sum_{i=1}^{n}(X_i-\bar X)=0
\]

所以如果前 \(n-1\) 个残差已经确定，第 \(n\) 个自动确定。

真正自由的信息只有：

\[
n-1
\]

因此：

\[
\boxed{
\text{估计了一个均值参数，就消耗了一个自由度}
}
\]

---

# 24. 无偏性与一致性的区别

## 无偏性

固定 \(n\)，重复抽样：

\[
\hat\theta^{(1)},
\hat\theta^{(2)},\ldots
\]

看这些估计量的中心：

\[
E(\hat\theta)
\]

是不是 \(\theta\)。

即：

\[
\boxed{
\text{固定样本容量，看重复抽样是否平均偏离}
}
\]

## 一致性

让：

\[
n\to\infty
\]

看：

\[
\hat\theta_n\to\theta
\]

即：

\[
\boxed{
\text{样本越来越多时，估计量是否收敛到真值}
}
\]

二者不是同一个性质。

---

# 25. 估计量的方差：无偏还不够

两个估计量都可能无偏：

\[
E(\hat\theta_1)
=
E(\hat\theta_2)
=
\theta
\]

但一个波动很大，一个很稳定。

稳定性由：

\[
Var(\hat\theta)
\]

衡量。

所以评价估计量时至少要看：

\[
\boxed{
\text{Bias}
+
\text{Variance}
}
\]

---

# 26. 加权估计

若有两个无偏估计：

\[
\hat\theta_1,\hat\theta_2
\]

构造：

\[
\hat\theta_3
=
a\hat\theta_1
+
(1-a)\hat\theta_2
\]

因为权重和为1，所以仍然无偏。

如果两者独立：

\[
Var(\hat\theta_3)
=
a^2\sigma_1^2
+
(1-a)^2\sigma_2^2
\]

选择 \(a\) 使方差最小，会得到：

\[
a
=
\frac{\sigma_2^2}
{\sigma_1^2+\sigma_2^2}
\]

最终体现的规律是：

\[
\boxed{
\text{方差越小、越可靠的估计，应该获得越大的权重}
}
\]

以后WLS和Kalman都还会看到这个思想。

---

# 27. 仿射组合与凸组合

PPT用几何解释加权组合。

若：

\[
p=\theta p_1+(1-\theta)p_2
\]

且：

\[
0\le\theta\le1
\]

则 \(p\) 位于 \(p_1,p_2\) 之间的线段上，属于凸组合。

这一部分对当前主线不是重点，只需要知道：

\[
\boxed{
\text{加权平均本质上是一种线性组合}
}
\]

---

# 28. MSE：把偏差和方差统一起来

定义：

\[
\boxed{
MSE(\hat\theta)
=
E[(\hat\theta-\theta)^2]
}
\]

可以分解为：

\[
\boxed{
MSE(\hat\theta)
=
Var(\hat\theta)
+
Bias(\hat\theta)^2
}
\]

这说明一个估计量即使有一点偏，但如果方差显著更小，综合误差仍可能更小。

因此：

\[
\boxed{
\text{无偏不等于一定最好}
}
\]

---

# 29. MVUE 与相对有效性

## 29.1 MVUE

Minimum Variance Unbiased Estimator：

\[
\boxed{\text{最小方差无偏估计量}}
\]

要求：

1. 无偏：
   \[
   E(\hat\theta)=\theta
   \]
2. 在无偏估计量中方差尽可能小。

## 29.2 相对有效性

如果两个估计量都无偏，可以比较方差。

方差越小：

\[
\boxed{\text{估计越有效}}
\]

PPT用样本均值与样本中位数作为比较例子。

---

# 30. 为什么还需要区间估计？

点估计给：

\[
\hat\theta=10.3
\]

但换一批样本可能得到：

\[
10.1,\quad10.5,\quad10.2
\]

说明：

\[
\hat\theta
\]

本身具有抽样波动。

于是我们不只想知道：

> 参数大概是多少？

还想知道：

> 这个估计的不确定性有多大？

这就是区间估计。

---

# 31. 抽样分布 Sampling Distribution

每次从总体抽 \(n\) 个样本，再计算一个统计量：

\[
T=T(X_1,\ldots,X_n)
\]

重复抽样时，\(T\) 会变化。

这些 \(T\) 自身形成的概率分布叫：

\[
\boxed{\text{抽样分布}}
\]

例如：

\[
\bar X
\]

的抽样分布，就是反复抽取 \(n\) 个样本并求均值时，所有样本均值形成的分布。

---

# 32. 样本均值的期望和方差

独立同分布时：

\[
\boxed{
E(\bar X)=\mu
}
\]

以及：

\[
\boxed{
Var(\bar X)
=
\frac{\sigma^2}{n}
}
\]

因此：

\[
SD(\bar X)
=
\frac{\sigma}{\sqrt n}
\]

这个量常称为样本均值的标准误：

\[
\boxed{
SE(\bar X)
=
\frac{\sigma}{\sqrt n}
}
\]

它表示：

> 不同样本之间，样本均值通常波动多大。

样本量越大：

\[
n\uparrow
\Rightarrow
SE\downarrow
\]

所以平均值越来越稳定。

---

# 33. 中心极限定理 CLT

在适当条件下，当 \(n\) 足够大：

\[
\boxed{
\bar X
\approx
N\left(
\mu,\frac{\sigma^2}{n}
\right)
}
\]

即使原总体不完全是正态分布，样本均值也常趋向正态。

如果总体本来就是正态：

\[
X\sim N(\mu,\sigma^2)
\]

则任意样本量下：

\[
\bar X
\sim
N\left(
\mu,\frac{\sigma^2}{n}
\right)
\]

PPT使用 \(n>30\) 作为“大样本”的经验规则之一；实际问题中是否足够仍取决于总体分布。

---

# 34. 从抽样分布进入置信区间

如果：

\[
\bar X
\sim
N\left(
\mu,\frac{\sigma^2}{n}
\right)
\]

则标准化：

\[
Z
=
\frac{\bar X-\mu}
{\sigma/\sqrt n}
\]

服从标准正态：

\[
Z\sim N(0,1)
\]

标准正态中：

\[
P(-1.96<Z<1.96)
\approx0.95
\]

代回去可得：

\[
P
\left(
\bar X
-
1.96\frac{\sigma}{\sqrt n}
<
\mu
<
\bar X
+
1.96\frac{\sigma}{\sqrt n}
\right)
\approx0.95
\]

于是95%置信区间：

\[
\boxed{
\bar x
\pm
1.96\frac{\sigma}{\sqrt n}
}
\]

---

# 35. 置信水平与显著水平

若：

\[
1-\alpha=0.95
\]

则：

\[
\alpha=0.05
\]

其中：

- \(1-\alpha\)：置信水平；
- \(\alpha\)：留在区间外的总概率，常称显著水平。

双边区间通常把：

\[
\alpha
\]

分到左右两端：

\[
\alpha/2
\]

---

# 36. 95%置信区间应该怎么理解？

频率统计中，总体参数：

\[
\mu
\]

被看作固定但未知。

随机的是由不同样本构造出的区间。

如果重复抽样并每次按同样方法构造区间：

\[
I_1,I_2,\ldots
\]

长期来看，大约95%的这些区间会覆盖真实参数 \(\mu\)。

所以更严谨的理解是：

\[
\boxed{
95\%\text{描述的是构造区间的方法的长期覆盖率}
}
\]

而不是把已经算出的固定区间解释成“\(\mu\) 有95%概率落进去”。

---

# 37. \(\sigma\) 未知时为什么出现 t 分布？

上面使用：

\[
Z
=
\frac{\bar X-\mu}{\sigma/\sqrt n}
\]

需要知道总体标准差 \(\sigma\)。

现实中 \(\sigma\) 往往未知，只能用样本标准差：

\[
S
\]

代替。

这时：

\[
\boxed{
T
=
\frac{\bar X-\mu}{S/\sqrt n}
}
\]

在正态总体条件下服从：

\[
\boxed{
t(n-1)
}
\]

其中自由度为：

\[
n-1
\]

原因正与前面样本方差中“估计均值消耗一个自由度”相连。

---

# 38. \(\chi^2\) 分布和 F 分布当前先记用途

PPT在区间估计中列出：

- 正态分布；
- \(t\) 分布；
- \(\chi^2\) 分布；
- \(F\) 分布。

当前阶段先建立用途地图即可：

| 问题 | 常见分布 |
|---|---|
| 均值，\(\sigma\) 已知 | Normal / Z |
| 均值，\(\sigma\) 未知 | \(t\) |
| 总体方差 \(\sigma^2\) | \(\chi^2\) |
| 两个方差之比 | \(F\) |

后续课程还会再次使用这些分布。

# 39. 正态分布的68–95–99.7规则

对于：

\[
X\sim N(\mu,\sigma^2)

大约：

\[
P(\mu-\sigma<X<\mu+\sigma)\approx68.3\%
\]

\[
P(\mu-2\sigma<X<\mu+2\sigma)\approx95.4\%
\]

\[
P(\mu-3\sigma<X<\mu+3\sigma)\approx99.7\%
