# 0. 这一课到底要解决什么问题？

第一课不是要你立刻掌握某个具体算法，而是先建立整门课的世界观：

\[
\boxed{
\text{复杂、带噪、多维的原始数据}
\rightarrow
\text{选择合适的数学表示}
\rightarrow
\text{建立模型}
\rightarrow
\text{提取规律/参数}
\rightarrow
\text{解释、预测、决策}
}
\]

后面会出现最小二乘、回归、相关、Fourier、PCA、SVD、Kalman、神经网络等很多方法。第一课的作用，是先告诉你：**这些方法并不是互不相干的工具，而是在不断把“复杂问题”改写成“更简单、更可计算的问题”。**

PPT把这种思路概括为：

- 降维；
- 线性化；
- 稀疏化；
- 最终原则：**Keep It Simple（KIS）**。

# 1. 什么是“测量数据”？

“测量数据”不必理解得特别物理化。对这门课而言，只要是由观测、实验、传感器、统计调查或模型输出得到的数据，都可以作为处理对象。

PPT列举的数据形式包括：

- 一维数据：例如时间序列；
- 二维数据：例如平面空间数据、图像；
- 三维数据：例如 \(X,Y,Z\) 空间数据；
- 四维数据：例如 \(X,Y,Z,T\)；
- 多维数据；
- 图像；
- 多源大数据。

## 1.1 一个最重要的区别：数据不是规律本身

例如你测量某个量得到：

\[
x_1,x_2,\ldots,x_n
\]

这些只是观测结果。它们可能同时包含：

\[
\boxed{
\text{真实规律}
+
\text{随机噪声}
+
\text{模型不完全}
+
\text{异常值/粗差}
}
\]

数据处理的目的不是“把公式套上去”，而是尽可能从这些观测中提取：

- 稳定结构；
- 参数；
- 关系；
- 时间/空间模式；
- 可用于预测的信息。

# 2. 数据处理与数据分析

PPT对两者做了一个很实用的区分。

## 2.1 数据处理

可以理解为：

> 已经选定了方法，对数据执行规定的数学操作。

例如：

- 做FFT；
- 做最小二乘；
- 标准化；
- 求协方差；
- 做PCA。

更偏“算法执行”。

## 2.2 数据分析

更强调：

> 为什么选择这个方法？结果是否合理？能说明什么？

所以同样一个相关系数 \(r=0.8\)，真正的数据分析还要问：

- 是否有离群值？
- 是否只是线性相关？
- 是否存在因果关系？
- 数据是否满足方法的假设？
- 结果在具体问题中是否有意义？

因此：

\[
\boxed{
\text{数据处理} \neq \text{数据分析}
}
\]

数据处理给你“数”，数据分析决定这个数是否值得相信、如何解释。

# 3. 第一课最重要的方法论：把复杂问题表示得更简单

## 3.1 降维

原始数据可能有很多变量：

\[
x_1,x_2,\ldots,x_p
\]

但真正起主要作用的方向或模式可能只有少数几个。

降维的目标不是简单“删变量”，而是：

\[
\boxed{
\text{用较少的自由度表示原来的主要信息}
}
\]

以后PCA、EOF、SVD都和这个思想有关。

## 3.2 线性化

复杂关系可能是：

\[
y=f(x)
\]

如果 \(f\) 非线性，直接求解往往困难。在某个工作点附近，可以用Taylor展开：

\[
f(x)
=
f(x_0)
+
f'(x_0)(x-x_0)
+
\frac12f''(x_0)(x-x_0)^2+\cdots
\]

只保留一阶项：

\[
f(x)\approx f(x_0)+f'(x_0)(x-x_0)
\]

就得到局部线性模型。

因此线性化的核心是：

\[
\boxed{
\text{用一个容易处理的线性近似代替局部复杂非线性关系}
}
\]

### 不要把“线性化”和“线性变换”混为一谈

- **线性化**：把非线性模型近似成线性模型；
- **线性变换**：一个映射本身满足线性性质。

两者有关，但不是同一个概念。

## 3.3 稀疏化

稀疏化不是简单地把数据拆成“有用信息 + 噪声”。

更准确的理解是：

> 为数据选择一个合适的表示空间，使大多数系数很小或为0，只剩少数重要系数。

例如某个信号在时间域很复杂，但在Fourier域可能主要只有几个频率分量：

\[
f(t)
\approx
a_1\cos\omega_1t
+
a_2\cos\omega_2t
\]

于是原本大量数据，被少数系数表示。

所以：

\[
\boxed{
\text{稀疏化}=
\text{寻找“少数系数就能表达主要信息”的表示}
}
\]

# 4. 后续课程会反复使用的数学语言

这一部分比历史人物更值得先弄清楚。

## 4.1 标量、向量与维度

标量是一个数：

\[
x
\]

向量是一组有顺序的数：

\[
\mathbf{x}
=
\begin{bmatrix}
x_1\\
x_2\\
\vdots\\
x_n
\end{bmatrix}
\]

可以把一个样本的多个特征看成一个向量，也可以把一段离散时间序列看成高维向量。

维度就是描述一个对象需要多少个独立坐标。

## 4.2 坐标与基

例如二维空间中一个向量：

\[
\mathbf{x}
=
\begin{bmatrix}
3\\
2
\end{bmatrix}
\]

这个“3、2”并不是向量本身的绝对属性，而是相对于某组基向量得到的坐标。

如果换一套基，同一个对象会得到另一组坐标。

因此：

\[
\boxed{
\text{对象本身}
\neq
\text{对象在某套基下的坐标}
}
\]

这是Fourier、PCA、特征向量等方法的共同基础。

## 4.3 基函数

普通向量空间使用基向量；函数空间可以使用基函数。

### 多项式基

\[
1,x,x^2,x^3,\ldots
\]

于是一个函数可以写成：

\[
f(x)
=
a_0+a_1x+a_2x^2+\cdots
\]

### Fourier基

\[
\cos(n\omega t),\quad\sin(n\omega t)
\]

于是：

\[
f(t)
=
a_0+\sum_{n=1}^{\infty}
\left[
a_n\cos(n\omega t)
+
b_n\sin(n\omega t)
\right]
\]

核心思想都是：

\[
\boxed{
\text{复杂对象}
=
\text{若干简单基的线性组合}
}
\]

## 4.4 线性组合

若有基：

\[
\mathbf{v}_1,\mathbf{v}_2,\ldots,\mathbf{v}_k
\]

则：

\[
\mathbf{x}
=
a_1\mathbf{v}_1+\cdots+a_k\mathbf{v}_k
\]

称为线性组合。

在数据处理中，我们经常真正想找的是：

\[
a_1,\ldots,a_k
\]

也就是“每个基对数据贡献多少”。

## 4.5 投影

把一个向量投到某个方向上，本质上是在问：

> 这个向量在这个方向上有多大成分？

如果 \(\mathbf{e}\) 是单位向量：

\[
\text{projection coefficient}
=
\mathbf{x}^{T}\mathbf{e}
\]

以后Fourier系数、PCA主成分、相关与向量夹角，都会重复出现“投影”思想。

## 4.6 矩阵

矩阵首先可以看作一个线性变换：

\[
\mathbf{y}=A\mathbf{x}
\]

这句话的意义是：

> 输入向量 \(\mathbf{x}\) 经过规则 \(A\)，得到输出 \(\mathbf{y}\)。

矩阵不是单纯“数字表格”，而是一个变换规则的代数表示。

# 5. 什么是线性变换？

若映射 \(F\) 满足：

\[
F(\mathbf{a}+\mathbf{b})
=
F(\mathbf{a})+F(\mathbf{b})
\]

以及：

\[
F(k\mathbf{a})
=
kF(\mathbf{a})
\]

则称它为线性变换。

也可合并为：

\[
F(\alpha\mathbf{a}+\beta\mathbf{b})
=
\alpha F(\mathbf{a})
+
\beta F(\mathbf{b})
\]

## 5.1 为什么数据处理中喜欢线性问题？

因为线性问题通常：

- 数学理论成熟；
- 矩阵可统一表达；
- 易于求解；
- 易于分解；
- 容易分析误差和稳定性。

所以后面的课程会不断把问题写成：

\[
\mathbf{y}=A\mathbf{x}
\]

或者局部近似成这种形式。

---

# 6. 特征向量与特征值：为什么有些方向特别重要？

若：

\[
A\mathbf{v}
=
\lambda\mathbf{v}
\]

那么 \(\mathbf{v}\) 是 \(A\) 的特征向量，\(\lambda\) 是对应特征值。

普通向量经过变换后方向通常会变，但特征向量方向不变，只改变长度：

\[
\mathbf{v}
\rightarrow\lambda\mathbf{v}
\]

所以可以把它理解为：

\[
\boxed{
\text{这个变换自身“天然偏好的方向”}
}
\]

以后PCA、EOF、SVD中寻找主要方向，都与这一思想相连。

---

# 7. Fourier变换在这里为什么出现？

PPT第一课不是要求你现在学会FFT，而是展示一种统一思想：

> 同一个数据，可以换一种“基”来表示。

时间序列在时间域：

\[
x(t)
\]

换到Fourier基后，可以表示成若干频率成分：

\[
x(t)
\leftrightarrow
\{a_k,b_k\}
\]

于是你看到的不再是“每个时间点的值”，而是：

- 有哪些频率；
- 各频率振幅多大；
- 相位是什么。

所以Fourier变换本质上可以先理解为：

\[
\boxed{
\text{从“时间坐标”换成“频率基上的坐标”}
}
\]

# 8. 最小二乘为什么在第一课历史部分占很大篇幅？

PPT用历史说明了一个非常重要的数据处理问题：

> 当观测比未知参数多，而且观测彼此矛盾时，“解”到底是什么？

假设：

\[
A\boldsymbol\theta\approx \mathbf{y}
\]

如果方程数多于未知数，通常不存在一个参数让所有方程严格成立。

于是定义残差：

\[
\mathbf{r}
=
\mathbf{y}-A\boldsymbol\theta
\]

最小二乘选择：

\[
\boxed{
\hat{\boldsymbol\theta}
=
\arg\min_{\boldsymbol\theta}
\sum_i r_i^2
}
\]

这体现了一种思想：

> 不要求每个观测都完美，而要求整体误差尽可能小。

PPT历史部分把这一方法和天文学、测地学中的超定方程联系起来，并强调它从“凑够方程求精确解”转向了“全部数据共同决定一个整体最优解”。

# 9. 真值、观测值、拟合值、误差和残差

假设真实规律：

\[
y_{\text{true}}
=
f(x)
\]

实际观测包含噪声：

\[
\boxed{
y_{\text{obs},i}
=
y_{\text{true},i}
+
\varepsilon_i
}
\]

其中：

- \(x_i\)：输入/自变量；
- \(y_{\text{true},i}\)：真实值；
- \(y_{\text{obs},i}\)：观测值；
- \(\varepsilon_i\)：观测随机误差。

我们根据数据估计模型参数，得到拟合值：

\[
\boxed{
\hat y_i
=
\hat f(x_i)
}
\]

于是残差：

\[
\boxed{
r_i
=
y_{\text{obs},i}
-
\hat y_i
}
\]

## 9.1 误差和残差不能混用

真实误差：

\[
\varepsilon_i
=
y_{\text{obs},i}
-
y_{\text{true},i}
\]

通常因为真值未知，所以无法直接算。

残差：

\[
r_i
=
y_{\text{obs},i}
-
\hat y_i
\]

可以直接计算。

如果模型完全正确：

\[
\hat y\approx y_{\text{true}}
\]

才有：

\[
r_i\approx\varepsilon_i
\]

如果模型本身就不对，那么：

\[
r_i
=
\underbrace{
(y_{\text{true},i}-\hat y_i)
}_{\text{模型误差}}
+
\underbrace{\varepsilon_i}_{\text{随机观测误差}}
\]

这正是PPT在回归历史部分强调的“拟合总误差 = 模型差异 + 随机噪声”。

---

# 10. \(x,y,a_0,a_1,\hat a,\tilde a\) 分别是什么？

PPT示例中真实模型可能写成：

\[
y=a_0+a_1x+a_2x^2
\]

这里：

- \(x\)：自变量/输入；
- \(y\)：因变量/输出；
- \(a_0,a_1,a_2\)：模型真实参数。

如果只用直线去拟合：

\[
\hat y
=
\hat a_0+\hat a_1x
\]

那么：

- \(\hat a_0,\hat a_1\)：根据样本估计得到的参数；
- \(\hat y\)：拟合/预测值。

PPT有时使用波浪号：

\[
\tilde a_0,\tilde a_1
\]

在该上下文中同样表示拟合得到的参数。一般教材中“帽子 \(\hat{}\)”更常表示估计值，而“波浪 \(\tilde{}\)”的含义依作者定义而变化，所以阅读时要看上下文。

# 11. 为什么正态分布和最小二乘会联系起来？

如果假设：

\[
\varepsilon_i\sim N(0,\sigma^2)
\]

且独立，那么一组观测出现的似然中包含：

\[
\exp\left(
-\frac{1}{2\sigma^2}
\sum_i r_i^2
\right)
\]

要让似然最大，就等价于让：

\[
\sum_i r_i^2
\]

最小。

因此在高斯误差假设下：

\[
\boxed{
\text{最小二乘}
\leftrightarrow
\text{最大似然}
}
\]

这也是为什么正态分布、LS和后面的参数估计会不断重新出现。

# 12. 回归和相关：第一课只需要建立正确直觉

## 12.1 回归

回归要做的是：

\[
\boxed{
\text{建立变量之间的模型关系}
}
\]

例如：

\[
Y=a+bX+\varepsilon
\]

用于解释或预测 \(Y\)。

“regression”这个名称历史上来自Galton研究中的“向均值回归”，**不是因为把点强行拉回一条线**。

## 12.2 相关

相关是在量化：

\[
\boxed{
\text{两个变量共同变化的强度与方向}
}
\]

Pearson相关系数主要反映**线性关系**。

因此：

- 相关高，不等于因果；
- 相关低，不等于完全没有关系；
- 可能存在很强的非线性关系但Pearson \(r\) 接近0。

所以不能把“相关”理解成“存在回归关系的概率”。

# 13. 历史部分怎么学：只保留“问题 → 方法”的线索

PPT用了大量历史。第一遍自学不需要记人物细节，只需要记方法为什么产生。

| 历史问题 | 形成的方法/思想 |
|---|---|
| 多次观测互相不完全一致 | 误差概念、平均 |
| 方程数多于未知数 | 最小二乘 |
| 为什么小误差多、大误差少 | 正态误差模型 |
| 如何从观测推断未知参数 | 似然/参数估计 |
| 两个变量怎样一起变化 | 回归、相关 |
| 模型误差与随机误差怎么区分 | 残差、方差分析思想 |

几个主要历史节点：

- 伽利略：早期观测误差思想；
- Legendre / Gauss：最小二乘；
- Gauss / Laplace：正态误差理论与中心极限定理；
- Galton：回归与相关思想；
- Edgeworth / Pearson / Yule：数学化、相关系数、LS与回归结合；
- Fisher：进一步形成现代统计推断体系。

这些历史内容的真正价值，是告诉你：

\[
\boxed{
\text{统计方法往往是为了解决具体数据矛盾而出现的}
}
\]

\boxed{
\text{很多复杂算法，本质上是在换空间、找基、投影、估参数。}
